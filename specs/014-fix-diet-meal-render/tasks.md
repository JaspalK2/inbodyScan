## Phase 2: Foundational (Blocking Both User Stories)

**Purpose**: Add the `normaliseMeal` helper that both US1 and US2 depend on. Must be complete before either story's rendering fix can be applied.

- [X] T00X In `frontend/app/(app)/recommendations/page.tsx`, add the `normaliseMeal(meal: any)` pure helper function immediately before the `DietDayRow` function definition (around line 614). It must implement these mapping rules:
  - `mealLabel`: `meal.meal_name` if present (already capitalised); else `(meal.meal as string)?.charAt(0).toUpperCase() + (meal.meal as string)?.slice(1)`; fallback `"Meal"`
  - `mealSlot`: `meal.meal` if present; else `(meal.meal_name ?? "").toLowerCase()`
  - `foods`: if `meal.foods` is a non-empty string array use it; else if `meal.items` is a non-empty object array map each item to `"${item.food_name} ${item.grams}g"`; else `[]`
  - `calories`: `meal.calories ?? meal.meal_totals?.calories ?? 0`
  - `protein_g`: `meal.protein_g ?? meal.meal_totals?.protein_g ?? 0`
  - `carbs_g`: `meal.carbs_g ?? meal.meal_totals?.carbs_g ?? 0`
  - `fat_g`: `meal.fat_g ?? meal.meal_totals?.fat_g ?? 0`
  - `fiber_g`: `meal.fiber_g ?? meal.meal_totals?.fiber_g ?? 0`
  - `_mf`: `meal._mf ?? []`
  Return type should be a local interface or inline type with all the above fields.

- [X] T00X [P] Write unit tests for `normaliseMeal` in `frontend/__tests__/recommendations/normaliseMeal.test.ts`. Cover:
  - (a) old LLM schema input `{meal:"breakfast", foods:["Oats 80g"], calories:400, protein_g:15, carbs_g:70, fat_g:8}` → `mealLabel="Breakfast"`, `mealSlot="breakfast"`, `foods=["Oats 80g"]`, `calories=400`
  - (b) new algorithmic schema input `{meal_name:"Breakfast", items:[{food_name:"Oats",grams:93.1}], meal_totals:{calories:550,protein_g:20,carbs_g:80,fat_g:10}}` → `mealLabel="Breakfast"`, `mealSlot="breakfast"`, `foods=["Oats 93.1g"]`, `calories=550`
  - (c) empty/missing schema `{}` → `mealLabel="Meal"`, `foods=[]`, all macros `0`
  - (d) mixed: `meal.meal` present AND `meal.items` present → prefers `meal.meal` for slot; prefers `meal.foods` if present, else falls back to `meal.items`

**Checkpoint**: `normaliseMeal` helper exists and its unit tests pass. Both user stories can now proceed.
